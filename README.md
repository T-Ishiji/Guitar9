# ギターコード v0.0.28

v0.0.26 を基準に、TypeScript 側だけにディレイ機能を追加した版です。

- 0 ms: 3音同時
- 正の値: 1→2→3
- 負の値: 3→1→2（Cならソ→ド→ミ）
- C++ (`multitone.cpp`) は v0.0.26 から変更していません。
- ボタン1=P1、ボタン2=P2、ボタン3=P9
- 出力=P8/P14/P16


## v0.0.29 オリジナル和音
ボタンを選び、3つの周波数を直接入力して割り当てるブロックを追加しました。

例: ボタン1 に 262 Hz・330 Hz・392 Hz を割り当てる → C相当。
ディレイ設定はプリセット和音とオリジナル和音の両方に適用されます。


## v0.0.30 音色（波形）

「音色（波形）を ～ にする」ブロックを追加しました。3出力すべてに共通で適用されます。

- スクエア 50%
- パルス 37.5%
- パルス 25%
- ナローパルス 12.5%
- ウルトラナロー 6.25%

これらは nRF52 のハードウェアPWMのパルス幅を変更する方式です。プリセット和音と3周波数の直接指定の両方に適用されます。


## v0.0.34 演奏モード
- 通常の和音（初期値）
- ユニゾン：3出力とも第1周波数
- 3倍音：第1周波数、2倍、3倍
- 金管（近似）：第1周波数、2倍、3倍 + パルス25%
- モードを設定しない場合は従来どおり「通常の和音」です。


## v0.0.35 ピン割り当て変更
- ボタン1 = P1
- ボタン2 = P2
- ボタン3 = P8
- 出力1 = P12
- 出力2 = P14
- 出力3 = P16

micro:bit V2では P8 は nRF52833 の P0.10、P12 は P0.12 に対応します。


## v0.0.36 ボタン同時押し
ボタンのプルダウンに以下を追加しました。

- ボタン1＋ボタン2
- ボタン2＋ボタン3
- ボタン1＋ボタン3
- ボタン1＋ボタン2＋ボタン3

物理ピン:
- ボタン1 = P1
- ボタン2 = P2
- ボタン3 = P8

同時押しは完全一致で判定します。たとえばボタン1＋ボタン2を押している間は、
ボタン1単独やボタン2単独の割り当ては発音しません。
約15msの安定判定を入れ、同時押し時の誤発音を抑えています。


## v0.0.37 ジョイスティック発音ゲート
### ボタン状態
- ボタンなし
- ボタン1
- ボタン2
- ボタン3
- ボタン1＋ボタン2
- ボタン2＋ボタン3
- ボタン1＋ボタン3
- ボタン1＋ボタン2＋ボタン3

### ジョイスティック
VR1 の接続:
- 6 = 3V
- 5 = micro:bit P0
- 4 = GND

P0 のアナログ値が中央付近（350～674）の間は必ず無音です。
350未満または674より大きいときだけ、現在のボタン状態に割り当てた和音を鳴らします。


## v0.0.38 ジョイスティック方向でストローク順を変更
VR1:
- 6 = 3V
- 5 = P0
- 4 = GND

ディレイが0以外の場合:
- 6側（3V側）へ倒す: 1→2→3（Cなら ド→ミ→ソ）
- 4側（GND側）へ倒す: 2→3→1（Cなら ミ→ソ→ド）

ディレイ値はジョイスティック発音では絶対値を使用します。
ジョイスティックを中央へ戻すか反対側へ切り替えると、一度停止して新しい方向で鳴り直します。


## v0.0.39 逆方向と即時切替
- 6側（3V側）: 1→2→3（Cなら ド→ミ→ソ）
- 4側（GND側）: 3→2→1（Cなら ソ→ミ→ド）
- ディレイ途中でも以下の変化を約5ms単位で監視:
  - ボタン状態の変更
  - ジョイスティック方向の変更
  - ジョイスティックを中央へ戻す
- 変化を検出したら現在の演奏を即停止し、watcherが新しい状態の和音を鳴らします。
